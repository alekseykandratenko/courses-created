# Python Programming Course

A comprehensive Python programming course structured in phases, focusing on fundamental concepts and practical applications.

## Course Structure

### Phase 1: Programming Fundamentals
1. **Basic Data Types and Structures**
   - Numbers and numeric operations
   - Strings and string manipulation
   - Lists and basic data structures
   - Input/Output operations
   - First programs and exercises

2. **Operators and Expressions**
   - Logical types
   - Relational operators
   - Logical operators
   - Nested expressions
   - Assignment operators

3. **Flow Control**
   - If statements
   - While loops
   - For loops
   - Post-analysis
   - Practice exercises

### Phase 2: Data Management and Optimization
1. **Data Collections**
   - Tuples
   - Sets
   - Dictionaries
   - Advanced data structures
   - Practice exercises

## Course Materials
- Jupyter notebooks with theory and examples
- Practice exercises with solutions
- Markdown documentation
- Supporting RTF documentation

## Learning Format
The course is structured using Jupyter Notebooks (.ipynb files) that combine:
- Theoretical explanations
- Code examples
- Interactive exercises
- Practice problems with solutions

## Prerequisites
- Basic computer knowledge
- Python installation
- Jupyter Notebook environment

## Course Goals
1. Understanding Python fundamentals
2. Mastering basic programming concepts
3. Learning data structures and their applications
4. Developing practical programming skills
5. Building a foundation for advanced Python programming

## Note
This course is designed for beginners and provides a structured approach to learning Python programming from the ground up.  
Course is wrote in spanish language.
